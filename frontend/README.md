# AI-EDM Campaign Management System
> 智能電子郵件行銷活動管理系統

## 📋 系統概述

本系統提供完整的 EDM 行銷活動管理流程，從活動設定、受眾選擇、內容編輯到追蹤分析的全方位解決方案。採用 Monica AI 設計風格，提供直觀且美觀的使用者介面。

## 🗂️ 文件結構

```
ai-edm/
├── README.md                    # 系統說明文件（本文件）
├── CLAUDE.md                    # 前端設計系統規範
├── campaign-edm.html            # 主頁面 - 活動列表管理
├── campaign-edm-1.html          # 步驟1 - 基本設定與排程
├── campaign-edm-2.html          # 步驟2 - 受眾選擇
├── campaign-edm-3.html          # 步驟3 - 內容編輯
├── campaign-edm-5.html          # 步驟4 - 開信追蹤設定
└── screenshot/                  # 系統截圖目錄
```

## 📄 頁面規格說明

### 1. 主頁面 - 活動列表管理 (`campaign-edm.html`)

**功能描述**: EDM 行銷活動的總覽和管理介面

**主要特色**:
- 📊 即時 KPI 儀表板（曝光次數、點擊率、轉換率）
- 📈 動態 SVG 成效圖表
- 🔍 多維度篩選功能（時間範圍、活動名稱、廣告名稱）
- 📋 PrimeNG 風格資料表格
- ⚡ 分頁與即時搜尋功能

**技術特點**:
- 採用 Monica AI 紫色主題 (`#7c3aed`)
- 響應式網格佈局 (Grid Layout)
- 原生 JavaScript 無外部依賴
- 即時資料篩選與分頁

**互動功能**:
- 活動狀態管理（執行中/暫停/未啟動）
- 批量操作（編輯、複製、刪除、暫停）
- 報表檢視與資料匯出
- 智能內容與郵件設定快捷入口

**資料結構**:
```javascript
{
  id: Number,           // 活動唯一識別碼
  name: String,         // 活動名稱
  status: String,       // 狀態: active/paused/inactive
  dayOfWeek: String,    // 發送星期
  hourOfDay: String,    // 發送時間
  startDate: String,    // 開始日期 YYYY/MM/DD
  endDate: String,      // 結束日期 YYYY/MM/DD
  lastUpdate: String,   // 最後更新時間
  user: String,         // 操作用戶
  impressions: Number,  // 曝光次數
  clicks: Number,       // 點擊次數
  conversions: Number   // 轉換次數
}
```

### 2. 步驟1 - 基本設定與排程 (`campaign-edm-1.html`)

**功能描述**: 設定活動基本資訊、發送排程和郵件模板

**核心功能**:
- 📝 活動基本資訊設定（名稱、日期、標籤）
- ⏰ 智能排程系統（頻率選擇、時間設定）
- 📧 郵件模板選擇（促銷、會員、關懷、邀請）
- 🎯 郵件狀態與設定管理

**排程功能特色**:
- **頻率選擇**: 單次發送/每日/每週/每月
- **時間選擇器**: 可視化時間調整器具
- **最佳化建議**: 20:00 推薦最佳開信率時段
- **快速設定**: 上班時間(09:00)、午休(12:00)、下班(18:00)

**模板系統**:
- 圖標化模板選擇界面
- 懸停動畫效果與選中狀態
- 響應式卡片佈局

**表單設定**:
- PrimeNG 風格表單元件
- 輸入群組（日期選擇器含圖標）
- 下拉選單（狀態、時區、簽名檔）
- 開關切換（訂閱會員限制）

**技術實現**:
- PrimeNG 風格步驟指示器
- 自定義時間選擇器元件
- 卡片選擇互動系統
- JavaScript 時間調整邏輯

### 3. 步驟2 - 受眾選擇 (`campaign-edm-2.html`)

**功能描述**: 選擇郵件寄送的目標受眾群體

**主要功能**:
- 🤖 AI 推薦分群（智能分析建議）
- 📋 既有分群選擇（已建立的客戶群組）
- ⚙️ 自訂分群建立（動態篩選條件）

**分群管理系統**:
- **既有分群**: 
  - 全部會員 (15,420人)
  - 高價值會員 (3,240人)
  - 已加入購物車 (2,458人) *預設選中*
  - 流失風險客戶 (1,876人)
  - 科技愛好者 (4,521人)
  - 門店VIP客戶 (987人)

- **自訂分群建立器**:
  - 會員標籤選擇（產品類別、顧客分群、生日月、性別）
  - 多條件篩選組合
  - 即時受眾規模預估
  - 篩選條件標籤管理

**互動特色**:
- 即時搜尋與分頁（每頁8筆）
- 單選電台按鈕設計
- 動態受眾規模更新
- 篩選條件可視化標籤

**資料結構**:
```javascript
// 分群資料模型
segments = [{
  id: Number,           // 分群ID
  name: String,         // 分群名稱
  count: String,        // 人數（格式化字串）
  unit: String,         // 單位（位客戶）
  description: String,  // 描述說明
  selected: Boolean     // 是否選中
}]

// 會員標籤模型
memberLabels = [{
  id: String,           // 唯一識別碼
  name: String,         // 標籤名稱
  count: String,        // 會員數量
  hasContent: Boolean   // 是否有子選項
}]
```

**技術實現**:
- 標籤式導航系統
- 動態表單建構
- 受眾數量即時計算
- 響應式卡片網格

### 4. 步驟3 - 內容編輯 (`campaign-edm-3.html`)

**功能描述**: 創建和編輯電子郵件內容，整合 AI 協助功能

**核心功能**:
- ✏️ 可摺疊郵件設定區（主旨、預覽文字、簽名檔）
- 📧 收件匣預覽即時更新
- 🏷️ 郵件類別與 AI 提示詞工程
- 🤖 AI 內容生成助手（整合 CKEditor 5）

**郵件設定系統**:
- **基本設定**: 主旨線、預覽文字、簽名檔選擇
- **即時預覽**: 模擬收件匣顯示效果
- **簽名檔選項**: 預設/行銷部門/客服部門/執行長/自訂

**AI 提示詞工程**:
- **類別選擇**: 促銷活動、電子報、歡迎信、提醒通知、重要公告、問卷調查
- **智能規範**: 依據類別提供對應的 AI 生成指導原則
- **自訂提示詞**: 額外的個性化內容指導

**內容編輯功能**:
- 整合 CKEditor 5 富文本編輯器
- AI 聊天助手側欄
- 變數插入器（客戶姓名、公司名稱等）
- 模板快速套用系統

**AI 聊天助手特色**:
- 即時內容建議與優化
- 快速操作標籤
- 上下文感知對話
- 多輪對話記錄

**模板系統**:
- **基本模板**: 經典郵件佈局
- **素材上傳**: 拖拽式檔案上傳
- **AI 分析**: 素材智能分析與建議

**技術實現**:
- CKEditor 5 整合
- 可摺疊面板設計
- AI 聊天界面
- 即時預覽更新
- 模板選擇器系統

## 🚀 使用方式

### 快速開始
1. 複製專案到本地環境
2. 使用 HTTP 服務器開啟 `campaign-edm.html`
3. 按照流程進行活動設定：
   - 基本設定 → 受眾選擇 → 內容編輯 → 追蹤設定

### 開發環境設置
```bash
# 使用 Python 簡易服務器
python -m http.server 8000

# 或使用 Node.js 服務器
npx http-server

# 或使用 Live Server 擴展（VSCode）
```

### 操作流程
1. **主頁面**: 查看現有活動，點擊「+ 新增」開始建立
2. **步驟1**: 設定活動名稱、時間、排程、模板
3. **步驟2**: 選擇目標受眾（既有分群或自訂分群）
4. **步驟3**: 編輯郵件內容（使用 AI 助手）
5. **步驟4**: 設定追蹤參數，測試發送
